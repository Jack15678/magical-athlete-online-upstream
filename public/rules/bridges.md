# Bridges：桥上、桥下与路线

依据：用户提供的 `bgg442655.pdf` 第1–2页地图、第3页作者规则与FAQ。

**这张图没有岔路选择。始终按 0→1→2→…→30 移动；交叉处不能换层或抄近路。**

|桥上格|桥下格|各自下一格|
|---|---|---|
|3|8|3→4；8→9|
|10|13|10→11；13→14|
|15|18|15→16；18→19|
|20|23|20→21；23→24|

桥上与桥下在空间上重叠，规则中的“同格”“越过”和“领先”有不同含义：

- **同格技能**：一对上下层通常算同格，两层可以互相影响。女巫、教练、决斗者、巨口、派对动物、浪漫主义者均如此。
- **越过技能**：从上层经过，会越过两层的选手；从下层经过，只会越过下层选手。上层经过下层的香蕉或半人马时，即使最后停在较小格号，也算移动后到了对方前面。
- **领先、落后与距离**：按格号从1到30计算。8格领先3格，两者不因重叠而并列；起哄者、催眠师、翻转人也按数字格位处理。

角色例外：

- **吸盘鱼**只能跟随同一格号的选手，不能隔层吸附。
- **跳蛙**遇到任一层有人，跳过自己的下一个数字格，例如2→4或7→9。
- **巨婴**停在桥的任一层，会把两层其他选手各沿自己的数字路线后推1格。被后推的香蕉等“被越过”反应，仅在起初与巨婴处于同一格号时影响巨婴。
- **电灯泡**把分居上下层的两人算作一对，可以选择传送到其中任意一人的格号。
- **飞艇**的第二弯道明确为15格。原图未定义第一弯道，网页按既定选择禁用依赖第一弯道的纨绔子弟。

上述基础角色规则来自作者FAQ；其他扩展角色沿网页已公开的同格、越过与距离分类执行，不表示作者逐一裁定过所有跨扩展组合。
