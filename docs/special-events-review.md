# 特殊赛事与规则补齐验收

本次基于地图版本后的 `main`，给新局加入 Thrilling Thirds 36 项特殊赛事，默认关闭，可指定场次。比赛界面显示当前赛事、规则与场上标记；秘密猜测通过原有选择队列、持久化和私人投影处理。事件收入、支出写入 `scoreLedger.event`。

## 实际修复

- Boardwalks 的 18→17 箭头与飞艇事件 / Whisper 形成重复选择链时，选择分支清除了循环检查点，最终进入诊断暂停。现保留同一移动链的检查点，两种可复现场景均有回归用例。
- 对照用户提供的官方 Second Wind PDF 第24–27页，核对36张卡及旁注，修正复仇者时机、魔法运动员并列目标、多野猪加成、替补演员目标、继父目标、复制黏黏怪及返场能力等。详细对应见[卡面核验](../public/rules/second-wind-verification.md)。
- 解开 Leaf + Second Wind 长赛程的整包限制，按实际选秀及私有牌资源预留验证组合，并覆盖所有包混合的完整长局。
- 固定骰与强制重掷、诅咒魔杖离场闭环、晚到的季终决战采用明确网页裁定，避免等待无可执行的规则选择；见[公开规则](../public/rules/competition.md)。

## 验证范围

- 最终本地全量测试 **1107/1107** 通过；客户端及 Worker 类型检查、构建、Worker dry-run 均通过。此前一轮为1106/1107，唯一失败是 Node 网络用例的 `fetch: bad port`；未改测试或业务代码，同一命令复跑全部通过。
- 36项赛事分别完成一场；2 / 3 / 8人 × 4 / 6 / 8场九组完整混合地图赛程，包含选秀唯一性、JSON恢复、逐场账本与最终积分核对。
- Worker 并发重复猜测、刷新重建、过期版本拒绝、秘密投影和只发一次奖励。
- 三个真实浏览器进行秘密猜测、刷新、状态同步；建房设置恢复、390px手机布局与赛事说明，2项浏览器用例通过并目检截图。
- 新局使用 `events-v1`。旧 `maps-v1` 引擎及 Twist 执行逻辑冻结，和旧基线逐字比较（除导入重定向）；旧赛程及 `fan-v3` 等继续使用原引擎。

## 规则边界

Thrilling Thirds 与多角色、扩展及分支地图的组合有公开网页改编，不宣称原作者已裁定全部组合，详见[36项赛事及组合规则](../public/rules/special-events.md)。骰子先生六骰各异时重掷仍遵从用户此前选定的房规；多角色仍采用固定行动顺序。

2026-10-24 更新：Whirly World 的原图完整端点仍有遮挡，但用户已选择六组传送的网页共创布局，模型和规则均已接入并开放，两套巡回恢复可选，见[来源调查与最新决定](whirly-world-source.md)。BGG 社区锦标赛按用户决定暂缓。
