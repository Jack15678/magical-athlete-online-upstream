# 首页入口 UI 验收

2026-10-22，基于主分支 `0d40493`。

首页改为四个入口：创建房间、现有房间、自己练习、人机对战。首次打开不选中入口，不渲染设置表单；点击后才展开。返回首页会关闭表单并保留各模式的设置草稿。

现有房间入口先展示昵称与房间列表，每个房间分别提供参赛和观战操作；房间码加入仍支持两种身份。邀请链接直接展开预填房间码的加入表单。桌面采用四列入口，手机采用两列。

验证结果：

- `pnpm typecheck`、`pnpm test`（906/906）通过。
- `pnpm build`（Node 客户端与浏览器托管客户端）、`pnpm exec wrangler deploy --dry-run` 通过。
- 首页专项与原配置草稿检查共 6 项通过，覆盖首次打开、返回、设置保留、键盘操作、房间码/列表参赛及观战、邀请链接。
- 一场八名独立玩家的服务器托管联机检查通过，覆盖房主/访客恢复、私密数据与桌面/手机布局。
- Worker 房间目录专项通过：满员仍能观战、退出后座位复用、重新加入使用正确身份。该项改为读取真实 WebSocket 公开快照，适配最新主分支的服务器托管方式。

截图来自本地构建的真实页面，使用桌面 1440px 与手机 390px 视口的无头 Edge。手机为浏览器视口模拟；尚未在实体手机或生产环境验收。构建保留原有的大体积资源提示。
